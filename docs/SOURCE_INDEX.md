## Regola per le fonti future

Ogni voce BOM deve riportare:

- data verifica;
- marca/modello;
- URL;
- prezzo;
- IVA inclusa/esclusa;
- disponibilità;
- specifiche critiche;
- classificazione `PREZZO TROVATO`, `PREZZO DA PREVENTIVO`, `BENCHMARK` oppure `STIMA`.
