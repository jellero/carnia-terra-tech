## Regola per le fonti future

Ogni nuova voce di BOM deve riportare almeno:

- data verifica;
- marca/modello;
- URL;
- prezzo;
- IVA inclusa/esclusa;
- disponibilità;
- specifiche critiche;
- nota `PREZZO TROVATO`, `PREZZO DA PREVENTIVO` oppure `STIMA`.
