# 08 — Automazione e dati

**Envelope:** €30.000  
**Classe:** A per controllo e dati essenziali; C per R&S avanzata

## Obiettivo

Automatizzare ciò che protegge produzione e riduce lavoro ripetitivo, senza far dipendere P1 da software sperimentale.

## A — realizzare subito

- PLC locali;
- I/O;
- sensori essenziali;
- rete OT;
- edge gateway;
- storage eventi;
- server minimo;
- backup;
- allarmi;
- dashboard;
- inventario asset;
- gestione utenti;
- tracciabilità lotti;
- ordini/consegne;
- interfaccia spaccio minima;
- osservabilità.

## P1 — funzioni attive

Ordine di maturità:
1. acquisizione dati;
2. allarmi;
3. report;
4. generazione attività;
5. comandi semplici entro limiti;
6. pianificazione operativa assistita.

## B — predisporre

- dock AMR;
- rete/canali per visione;
- potenza per edge aggiuntivi;
- API stabili;
- modello eventi riusabile.

## C — rinviare

- GPU;
- AI avanzata;
- smart cart;
- smart crate;
- sensor fusion retail;
- robotica sperimentale;
- ottimizzatori complessi non ancora necessari.

## Sequenza

1. lista segnali P1;
2. architettura rete;
3. I/O;
4. PLC;
5. edge;
6. server minimo;
7. backup;
8. dashboard;
9. integrazione acqua/clima/energia;
10. ordini/tracciabilità;
11. test offline;
12. disaster recovery.

## Verifica settore

GO se:
- perdita server non rende l'impianto insicuro;
- PLC continua il minimo locale;
- backup ripristinabile;
- allarmi arrivano;
- dati timestampati;
- nessun ruolo critico dipende da una password personale;
- procedure manuali disponibili.

## Stop

Nessun software R&S è requisito per il primo raccolto.
